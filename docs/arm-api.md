# ARM API

The active adapter and source-verification profile are documented in [compatibility.md](../arm-season-queue/docs/compatibility.md). This identifies the actual endpoints and source behavior examined, including title-selection and holding limitations. A matching version string does not prove deployment compatibility.

Set `ARM_URL` and optional `ARM_BEARER_TOKEN` through environment variables. No live ARM deployment has been tested in this update. Historical configurable-route code under `arm_ripper_vision/arm/` belongs to the retained legacy controller.
